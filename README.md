# 🏦 Java Bank Account Management System

A console-based Banking System built using Java OOPS concepts - Part of my BCA 2nd Year journey at Asansol Engineering College.

### ✨ Features
- Create New Bank Account
- Deposit Money
- Withdraw Money
- Check Balance
- View All Accounts
- OOPS Concepts: Encapsulation, Classes, ArrayList

### 🛠️ Tech Stack
- Java (Core Java)
- OOPS Principles
- VS Code

### 🚀 How to Run
1. Clone: `git clone https://github.com/S433221/java-Bank-Account-management-system`
2. Run `Main.java`
